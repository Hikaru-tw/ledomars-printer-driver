
                    Using LEDOMARS Printer Driver
                Microsoft(R) Windows(R) Windows 8/10


This folder incorporates the printer driver for the LEDOMARS Printers 
to be used in Microsoft Windows 8. This [\BP9000EWIN8Driver] 
directory now includes the following printer driver files:

     * LP-7800IV

As for installing the printer driver and setting the printers, 
please refer to the follows:


<<<<< Installing the Printer Driver >>>>>

Use the "SETUP" program
 1. Please connect the printer to the computer with an interface cable, and then power on the printer.
 2. Double click the named "setup.exe" program which in the folder of "\BP9000EWIN8Driver" in the driver disk.
 3. Select the printer in the "Select Printer Driver" window and click the "Install" button. 
 4. If the "Hardware Installation" window pops up, select "Continue Anyway".
 5. Click the "Exit" button after installation succeed.

Or use the "Add the printer" wizard
 1. Click the <Start> button.
 2. Click <Control Panel> then click <Hardware and Sound>.
 3. Click the <Printers> menu.
 4. Click the < Add a Printer> icon.
 5. In the Add Printer wizard, select the <NEXT> button.
 6. Click the < Have disk...> button and select the path "\BP9000EWIN8Driver"
   for the dialog box "Copy manufactures files from:".
 7. Choose <OK> button.
 8. As for instructions about how to configure your printer, please refer to Microsoft 
   Windows User's Manual.
