
                    Using LEDOMARS Printer Driver
                Microsoft(R) Windows(R) Win8


This folder incorporates the printer driver for the LEDOMARS Printers 
to be used in Microsoft Windows Win8. This [\ENGLISH\WINDOWS8] 
directory now includes the following printer driver files:

     * LP-7580

As for installing the printer driver and setting the Printers, refer to the 
following:


<<<<< Installing the Printer Driver >>>>>

Use the "SETUP" program
 1. Please connect your printer to your computer with a interface cable, and then power on your printer.
 2. Double click the named "setup.exe" program in the folder of "\WINDOWS8" in the driver disk.
 3. Select the printer in the "Select Printer Driver" window and click the "Install" button. 
 4. If a "Hardware Installation" window pops up, select "Continue Anyway".
 5. Click the "Exit" button after installation successful.

Or use the "Add the printer" wizard
 1. Click the <Start> button.
 2. Point the <Setting> menu.
 3. Click the <Printers> menu.
 4. In the Printers Window, double-click the < Add Printer> icon.
 5. In the Add Printer wizard, click the <NEXT> button.
 6. Click the < Have disk...> button and select the path "\ENGLISH\WINDOWS8"
   for the dialog box "Copy manufactures files from:".
 7. Choose <OK> button.
 8. For instructions on how to configure your printer, please see Microsoft 
   Windows User's Manual.
